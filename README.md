# 🚀 JobZone — MERN Stack Job Portal

A full-stack job portal platform where employers can post jobs and job seekers can apply, built using the MERN stack and deployed on Vercel + Render.

---

## 🌐 Live Demo

- **Frontend (Vercel):** https://job-zone-blond.vercel.app  
- **Backend (Render):** https://job-zone-1.onrender.com  

---

## 📌 Features

### 👨‍💼 Employer
- Secure registration & login
- Post new jobs
- Manage posted jobs
- View applications from job seekers

### 👩‍💻 Job Seeker
- Register & login
- Browse all available jobs
- Apply to jobs
- Track applied jobs

### 🔐 Authentication & Security
- JWT-based authentication
- Authorization header protected routes
- Role-based access (Employer / Job Seeker)
- Secure API integration

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Axios
- React Router
- Context API
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary (file upload)

### Deployment
- Frontend → Vercel
- Backend → Render
- Database → MongoDB Atlas
